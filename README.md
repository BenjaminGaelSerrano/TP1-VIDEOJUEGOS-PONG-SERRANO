# Guía de Usuario: Pong Custom

## 1. Introducción
Pong es un simulador de tenis de mesa virtual. El juego consiste en una competencia de tablero bidimensional donde dos elementos laterales actúan como paletas para golpear un proyectil en movimiento. El objetivo principal es reaccionar a la trayectoria de la pelota y evitar que esta traspase el límite del área propia, mientras se intenta superar la defensa del oponente.

## 2. Descripción del Proyecto
Esta versión particular permite disputar partidas de habilidad y reflejos, con la posibilidad de ajustar la dificultad mediante la modificación de la velocidad de la pelota en tiempo real a través de una interfaz de usuario integrada.

## 3. Instrucciones de Control
Para operar el juego, el usuario debe utilizar los siguientes periféricos:

* [cite_start]**Movimiento de la Paleta**: El usuario debe utilizar las teclas **W** y **S** y para usar el otro jugador las flechas **Arriba** y **Abajo** para desplazar la paleta de forma vertical y realizar el impacto con la pelota. [cite: 1]
* [cite_start]**Activación de Pausa**: La presión de la tecla **Esc** detiene la ejecución del juego y despliega el menú de opciones en pantalla. [cite: 1]
* [cite_start]**Navegación por Interfaz**: Una vez activado el estado de pausa, se requiere el uso del **puntero del mouse** para interactuar con los botones de la interfaz. [cite: 1]

## 4. Funcionamiento del Menú de Pausa
Al ingresar a la interfaz de pausa, el sistema ofrece las siguientes funcionalidades:

* [cite_start]**Reanudar**: Restablece la ejecución del juego manteniendo la posición y el estado actual de todos los elementos en escena. [cite: 1, 2]
* [cite_start]**Ajuste de Velocidad**: El menú dispone de selectores que modifican la rapidez de la pelota de manera inmediata: [cite: 1, 2]
    * [cite_start]**Velocidad Normal**: Establece el ritmo de juego a su valor estándar. [cite: 1, 2]
    * [cite_start]**Velocidad Aumentada 1**: Incrementa la rapidez de la pelota x1,25 para una mayor dificultad. [cite: 1, 2]
    * [cite_start]**Velocidad Aumentada 2**: Configura la pelota a su máxima rapidez x1,5. [cite: 1, 2]

## 5. Objetivo del Juego
Anotar mas puntos que el otro.
